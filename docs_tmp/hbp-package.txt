2.2 西医方案生成逻辑
西医方案基于明确诊断、客观测量指标与药物治疗信息，规则性强，重在监测与及时干预。
2.2.1 症状评估与管理
依赖字段：西医诊断、症状标签历史记录。
采集方式：系统定期（如每周）根据疾病关联的关键症状库，向用户推送《症状自评
量表》（需产品经理为各慢性病配置症状库）。
逻辑： 
接收填报表数据，与历史趋势对比。
新发症状或原有症状加重超过阈值时，自动触发预警（微信/App通知），建议线
上问诊或复诊，并自动在医生端标红。
2.2.2 核心指标检测与提醒
依赖字段：各类医学指标（如血压、血糖）、医生设定的控制目标值范围、是否开启
智能设备连接。
采集方式：蓝牙设备自动传输、用户手动输入、检验报告OCR导入。
逻辑： 
频率管理：根据疾病风险等级，从规则库读取建议测量频率（如高危每日，中危
每周），在首页生成测量任务。
趋势分析：绘制指标趋势图，标注正常/异常区间。
阈值预警：配置“危急值”和“异常升高/降低”阈值表。一旦指标触及危急值（如收缩
压≥180mmHg），立即触发强提醒（需用户确认），并通知紧急联系人/医生端。

综上，当“生成方案”事件被触发（如新用户注册、定期更新、数据变更），系统执行以下步
骤：
数据准备与校验：读取健康档案所有必要字段。检查必填项，缺失项触发对应的采集任务
（问卷、设备连接引导、AI辨证等）。
健康评价：运行西医风险分层算法、中医证型映射，生成当前健康状态标签集。
方案生成：将“用户标签集 + 数据集”输入规则引擎和AI生成模型。规则引擎确保安全底线与
循证框架；AI模型负责个性化填充、文案撰写、内容润色。

颈部负担，影响脑部供血，诱发头晕；④ 避免擅自停用或减量降压药、中药，严格遵循用药管
理方案，杜绝自行调整用药的不良习惯。
4. 习惯监测与调整：每周记录不良习惯改善情况（如是否规律作息、是否控制盐油摄入），结
合血压、体重变化，分析不良习惯对病情的影响；若出现不良习惯反弹，及时自我提醒，或寻
摩）。

2.2.6.2 居住环境管理
核心原则：营造安静、舒适、平和的居住环境，适配肝阳上亢证患者“忌烦躁、宜舒缓”的需
求，减少环境刺激，辅助稳定情绪、控制血压。
1. 环境安静：居住环境需保持安静，避免嘈杂声音（如高分贝噪音、频繁噪音）刺激，噪音会
诱发情绪烦躁、血压升高，加重肝阳上亢症状；若环境噪音较大，可使用耳塞、窗帘等减少噪
音干扰。
2. 光线适宜：室内光线以柔和、自然为宜，避免强光直射（如正午阳光直射室内），强光会刺
激神经系统，诱发烦躁、头晕；夜间照明采用柔和的台灯（亮度适中），避免开灯睡觉，以免
影响睡眠质量。
3. 温湿度调节：室内温度保持在22-26℃，湿度保持在50%-60%，避免温度过高（＞28℃）
或过低（＜20℃），避免湿度过大（＞70%）或过小（＜40%）；温度过高易导致烦躁、出
汗，温度过低易受凉，湿度过大易滋生湿气（加重肥胖痰湿内蕴），湿度过小易导致口干、烦
躁，均不利于病情调理。
4. 环境布局：室内布局简洁、整洁，避免杂乱无章（杂乱环境易导致情绪烦躁）；可摆放绿色
植物（如绿萝、吊兰、菊花），既能净化空气，又能舒缓情绪，辅助平肝潜阳；避免摆放刺激
性气味的物品（如浓烈香水、油漆），以免刺激呼吸道和神经系统，诱发不适。
出处来源：《中医环境养生指南》（中华中医药学会）、《健康居住环境规范》（国家卫生健
康委员会），明确适宜的居住环境对慢病患者病情控制的辅助作用。
